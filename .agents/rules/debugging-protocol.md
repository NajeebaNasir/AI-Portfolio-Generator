# Debugging & Issue Explanation Protocol

## Mandatory Rule
Whenever the user asks to debug, fix, or investigate any error or unexpected behavior:
1. **Always state FIRST what the exact issue/root cause encountered was** before explaining the solution or applying the fix.
2. Structure the response clearly:
   - **Root Cause & Encountered Issue**: Concise, plain explanation of what broke and why.
   - **Fix Applied / Proposed**: Exactly what was changed to resolve it.
   - **Verification / Next Steps**: How it was verified.
